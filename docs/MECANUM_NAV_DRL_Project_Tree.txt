NGUYÊN TẮC KIẾN TRÚC
// State estimation tạo odometry cục bộ; localization xác định robot trên map.
// Nav2 Global Planner tạo global path; PPO chỉ là local controller trong HYBRID_AI_LOCAL.
// Nav2 Controller chỉ chạy trong NAV2_BASELINE; không chạy đồng thời với PPO controller.
// SafetySupervisor là tầng duy nhất chọn, giới hạn và xuất lệnh cuối tới /cmd_vel.
// Ground truth chỉ dùng bởi TrainingTaskOracle/evaluator; không vào policy observation hoặc TF chính.
// Cây TF chính: map -> odom -> base_link -> lidar_frame.
// Một TF edge, actuator topic, map và wheel-odometry contract chỉ có một chủ sở hữu.

BỐN CHẾ ĐỘ VẬN HÀNH
// LOCAL_TRAINING: LiDAR + noisy simulated odometry + local goal -> PPO -> Safety -> simulator.
// MAPPING: LiDAR + EKF -> SLAM Toolbox; teleop -> Safety -> robot.
// NAV2_BASELINE: Nav2 Planner + holonomic Controller -> Safety; không chạy PPO controller.
// HYBRID_AI_LOCAL: Nav2 Planner -> LocalReference -> PPO local controller -> Safety.

QUY TẮC SỞ HỮU
// mecanum_base_bridge sở hữu forward kinematics và /wheel/odometry_raw nhưng không phát TF.
// EKF là publisher duy nhất của odom -> base_link trong integration/deployment profiles.
// MAPPING: SLAM Toolbox sở hữu map -> odom. NAV2_BASELINE/HYBRID: AMCL sở hữu map -> odom.
// mecanum_nav_bringup sở hữu system launch và config EKF/SLAM/AMCL/Nav2/Safety.
// mecanum_nav_rl sở hữu DRL, HybridNavigationManager, LocalReference, evaluation và policy nodes.
// SafetySupervisor là publisher duy nhất của /cmd_vel.
// Trong HYBRID_AI_LOCAL, NavigationState là safety input; mất/stale/sai epoch-generation phải dừng.
// artifacts/maps là nguồn map chuẩn; map_manifest.json khóa nội dung map.
// artifacts/hardware/<id>/hardware_manifest.yaml là nguồn duy nhất cho thông số bánh xe.
// wheel_geometry.yaml và kinematics_params.h phải được sinh/xác minh bằng hardware_config_hash.
// Physical E-stop độc lập Linux, ROS 2, DDS và Python.
